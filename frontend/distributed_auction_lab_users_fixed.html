    StyleProcedure-oriented, calls functionsObject-oriented, calls methods on objects

    RPC: pass by value

    Client has A=5 and B=6. The server receives its own copies at its own addresses. Nothing links back to the client's memory.

    RMI: pass by reference

    The client holds a stub. The real object and its state stay on the server, and the client only holds a handle to it.
